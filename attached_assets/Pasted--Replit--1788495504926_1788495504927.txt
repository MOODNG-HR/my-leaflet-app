좋아, 이제 위 연차 산정 로직을 코어 엔진으로 하는 "연차 신청 웹사이트"를
Replit에서 풀스택으로 만들어줘. 요구사항은 아래와 같아.

■ 전체 구조
- 일반 직원용 페이지(신청자 페이지)와 관리자 전용 페이지(관리자 페이지)를 분리한다
- 관리자 페이지는 별도 URL 경로(예: /admin)로 접근하며,
  "관리자 권한이 부여된 계정"만 로그인/접근이 가능하다
- 일반 직원 계정으로는 관리자 페이지에 절대 접근할 수 없어야 한다 (라우트 가드/권한 체크 필수)

■ 계정 및 권한
- 사용자 역할(role)은 최소 2가지: "직원(employee)", "관리자(admin)"
- 회원가입/계정 생성은 관리자가 직원을 등록하는 방식으로 하거나,
  직원이 가입 신청 → 관리자가 승인하는 방식 중 더 안전한 쪽으로 제안해줘
- 로그인은 사번 또는 이메일 + 비밀번호 방식
- 비밀번호는 반드시 해시 처리(bcrypt 등)해서 저장
- 세션/토큰 기반 인증 적용, 로그인하지 않은 사용자는 모든 페이지 접근 차단

■ [신청자(직원) 페이지] 기능
1. 로그인 후 대시보드에서 본인의 "잔여연차 일수"를 바로 확인 가능
   - 이월연차 / 당해연도 발생연차 / 사용연차 / 잔여연차를 구분해서 표시
2. 연차 신청 폼
   - 신청 유형: 연차(1일), 반차(오전/오후, 0.5일), 특별휴가(선택)
   - 신청 시작일 / 종료일(또는 반차의 경우 해당일) 선택 → 자동으로 사용일수 계산
   - 사유 입력(선택 또는 필수, 정책에 맞게 설정)
   - 신청 시 잔여연차보다 많은 일수를 신청하면 즉시 경고/제한
3. 본인의 연차 신청 내역 조회 (신청일, 기간, 상태: 대기중/승인/반려/취소)
4. 대기중인 신청은 본인이 취소 가능
5. 모바일에서도 사용하기 편한 반응형 UI

■ [관리자 페이지] 기능
1. 로그인은 admin 권한 계정만 가능 (권한 없는 계정 접근 시 접근 거부 및 로그인 페이지로 리다이렉트)
2. 연차 신청 현황 대시보드
   - 전체 직원의 연차 신청 목록을 한눈에 확인 (부서/직원별 필터, 상태별 필터, 기간별 필터)
   - 대기중인 신청 건에 대해 승인/반려 처리 가능 (반려 시 사유 입력)
   - 승인/반려 처리 시 신청자에게 상태 반영(알림 기능은 우선순위 낮게 잡아도 됨)
3. 전 직원 잔여연차 현황 조회
   - 부서별/직원별로 이월연차, 당해연도 발생연차, 사용연차, 잔여연차를 표(테이블)로 조회
   - 특정 직원 클릭 시 해당 직원의 연차 발생/사용 상세 이력(로그) 확인 가능
   - 엑셀(CSV) 다운로드 기능 (기존에 쓰던 연차관리대장 형태로 내보낼 수 있게)
4. 직원 정보 관리
   - 직원 등록/수정/퇴사 처리
   - 입사일, 통상시급, 부서, 직급 등 연차 계산에 필요한 정보 입력/수정
5. 연차 수동 조정 기능
   - 결근 차감, 특별 부여 등 예외 상황에 대해 관리자가 수동으로 연차를 가감할 수 있는 기능
   - 수동 조정 시 사유를 반드시 남기고 변경 이력(audit log)을 저장
6. (선택) 연차사용촉진 관리
   - 특정 직원/기간에 대해 촉진통보 발송 여부, 임의지정 통지 여부를 기록
   - 촉진 절차 진행 여부에 따라 소멸/정산 대상 자동 구분

■ 데이터베이스 설계 시 최소 포함 테이블
- users (계정: 사번, 이름, 이메일, 비밀번호해시, role, 부서, 직급, 입사일, 재직상태, 통상시급 등)
- leave_requests (신청내역: 신청자ID, 유형, 시작일, 종료일, 신청일수, 사유, 상태, 처리자ID, 처리일시, 반려사유)
- leave_balances (연차현황: 직원ID, 연도, 이월연차, 발생연차, 사용연차, 잔여연차)
- leave_adjustments (수동조정 로그: 직원ID, 조정일, 조정일수, 사유, 처리자ID)
- (선택) leave_promotions (촉진절차 기록: 직원ID, 연도, 1차통보일, 2차통보일, 소멸/정산여부)

■ 기타 요구사항
- 신청/승인 처리 시 leave_balances가 자동으로 갱신되도록 트랜잭션 처리
- 관리자 계정 생성은 최초 1개는 시드 데이터로, 이후 추가 관리자는 기존 관리자만 지정 가능하게
- 향후 실제 회사 도메인/사내망 배포를 고려해 환경변수로 DB 연결정보 등을 분리
- 우선 MVP로는 로그인/권한, 신청, 승인, 잔여연차 조회 기능부터 구현하고,
  이후 촉진관리/엑셀다운로드/알림 기능을 단계적으로 추가하는 순서로 진행해줘

먼저 데이터베이스 스키마와 전체 폴더/파일 구조부터 설계안으로 제시해줘.
